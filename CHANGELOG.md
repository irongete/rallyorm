# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and the project follows Semantic Versioning.

## [1.0.0] - 2026-03-23

### Added
- Initial public release of RallyORM.
- TypeScript-first Rally API client, data source, repositories and entity models.
- Query helpers, relationship loading, dirty checking and custom field helpers.
- Read-only-by-default write permissions with explicit opt-in for create, update and delete.

### Notes
- Package is ESM-only.
- Supported runtime is Node.js 18 or newer.
